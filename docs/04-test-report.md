## Что проверяют тесты

- **Реестр предметов:** семь предметов в заданном порядке; уникальные id и префиксы; префикс не совпадает с экранами приложения; значок есть в наборе иконок; список встроенных учебных баз совпадает с реестром; у каждого предмета есть исходники, журнал и отчёт.
- **Учебные базы всех предметов** (проверки идут по реестру — новый материал проверяется без правки тестов): ID с префиксом предмета, ссылки на существующие страницы, KaTeX, независимый пересчёт числовых ответов, уникальность, ссылки на формулы, замечания к источнику, отчёты импорта, безопасность анимаций, дополнения из интернета, пустой предмет действительно пуст.
- **Логика:** проверка ответов всех типов, подсказка после первой ошибки, разбор после второй, режимы «по порядку» и «случайный», лимит времени, очередь ошибок, статистика, поиск, подписи страниц.
- **Вид для студентов и релиз:** замечания к источнику не видны студентам, исправленный текст входит в хеш и требует повторного утверждения, в релиз попадают только утверждённые записи, PIN — только хеш PBKDF2.
- **E2E (Chromium, ширина 320–768 px):** стартовый экран и переходы между предметами, учебник, тема с анимацией и формулами, вход в админ-панель только по PIN владельца, утверждение, все режимы тестов, ошибки и подсказки, работа без сети, тёмная тема, сброс прогресса, учебник с планом курса, раздельные данные предметов, отсутствие горизонтальной прокрутки и ошибок JavaScript.
- **Облако (имитация базы артефакта):** решения и прогресс переживают пустую память браузера, видны на другом устройстве без перезагрузки; у каждого предмета свои документы; общие настройки синхронизируются; не владелец не может изменить общую базу.
- **БД:** RLS, публикация только администратором, предметы публикуются независимо (номер версии уникален в пределах предмета), неверный id предмета отклоняется.

## Найдено и исправлено при переносе

- Human Performance and Medicine: тест «замечания к источнику» не пропустил замечание hpm-e02 с предложением «Проверить нумерацию частей» — переписано конкретно. На ширине 360 px широкие таблицы разбивали слова по буквам — в этом предмете они переданы списками.

- Circuit Theory: тест «вид для студентов» нашёл в пояснении лабораторной ссылку на номер замечания (ct-e05) — убрана, студенты номеров замечаний не видят.

- Mathematics III: заголовки карточек теории, формул и примеров показывали формулы исходным текстом `$…$`, а длинный заголовок-формула выталкивал карточку за край экрана на 320 px — заголовки теперь отображаются с KaTeX (во всех предметах, в поиске, на карточках и в админ-панели); слишком длинный ответ к задаче 4 лекции 5 разбит на части.

- Длинное название формулы при крупном шрифте на ширине 320 px выталкивало значок «на проверке» за край экрана (было и в UTC Preparation) — заголовок карточки формулы теперь переносится.
- В Supabase номер версии учебной базы был общим для всех предметов: два предмета, собранные в одну секунду, перезаписали бы версии друг друга. Миграция 0002 делает номер уникальным в пределах предмета.

## Что не проверялось

- Сборка Android и iOS для AE (скрипт перенесён и проверен только разбором PowerShell 7; на телефоне AE ещё не собирался).
- Живой сервер Supabase.
- Проверка типов TypeScript целиком: в среде разработки нет пакетов `@types/react` (реестр npm недоступен), поэтому `tsc` выдаёт ошибки типов React; новых ошибок по сравнению с UTC Preparation нет (число ошибок `tsc` совпадает).

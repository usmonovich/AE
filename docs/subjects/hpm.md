# 🩺 Human Performance and Medicine — журнал предмета

Журнал ведётся вручную при каждом поступлении материалов. Записи только добавляются (старые не удаляются и не переписываются).
Автоматический отчёт о содержимом учебной базы — [hpm-report.md](hpm-report.md) (его создаёт `npm run content:build`).

| Поле | Значение |
|---|---|
| id предмета | `hpm` |
| Адрес в приложении | `#/hpm` |
| Префикс ID тем и записей | `hpm-` |
| Исходники | `content/subjects/hpm/src/*.yaml` |
| Стиль | `notes` (материалы по страницам файлов; можно сменить на `book`, если основа — учебник с оглавлением) |
| Статус | курс готовится — материалов пока нет |

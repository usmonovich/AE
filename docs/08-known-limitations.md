# Известные ограничения

- **Предметы пока пустые.** Все семь предметов созданы со статусом «курс готовится»: учебные материалы ещё не присланы, поэтому тем, теории и тестов нет.
- **Стиль предметов.** Сейчас у всех предметов `style: notes` (материалы по страницам файлов). Если основой предмета окажется учебник с оглавлением, стиль меняется на `book` в `content/subjects.json` — до появления материалов, иначе придётся перепроверить записи.
- **Android и iOS.** Идентификатор `uz.husniddin.ae`, значок и скрипт сборки подготовлены, но AE ещё не собирался на телефоне и не опубликован в магазинах.
- **GitHub Pages.** Сайт собирается автоматически, но включить Pages (Settings → Pages → Source: GitHub Actions) и задать описание репозитория может только владелец.
- **Админ-панель.** Есть только в личной версии (опубликованная страница в Claude) и открывается по PIN владельца; хеш PIN — в файле `.admin-pin`, которого нет в репозитории.
- **Синхронизация через Supabase** написана и проверена на Postgres 16, но на живом сервере не проверялась.
- **Распознавание рукописей** (`tools/import/transcribe.mjs`) требует ключ API на компьютере владельца; в среде разработки не запускалось.
- **Фото страниц** материалов не публикуются в репозитории; в публичной сборке вместо них показывается пояснение.

# Тексты для магазинов

Черновик: описание предметов дополняется по мере наполнения курса. Пока все предметы пустые — публиковать в магазинах рано.

**Название:** AE
**Короткое описание (Google Play, до 80 знаков):** Учебные предметы: теория, формулы, тесты с подсказками и прогресс.
**Подзаголовок (App Store, до 30 знаков):** Теория, формулы и тесты

**Полное описание:**
AE — учебное приложение по предметам курса. На стартовом экране — список предметов; у каждого свой прогресс, тесты и избранное.

Предметы: Aviation Psychology and Crew Resource Management (CRM), Circuit Theory, Cost Engineering, Human Performance and Medicine, Hydraulics and Hydraulic Systems, Mathematics III, Mechanics.

• Учебник: раздел → подраздел → тема — теория, формулы с расшифровкой обозначений, разобранные примеры
• Тесты по теме, подразделу или всему предмету — по порядку материалов или в случайном порядке
• Ошиблись — получите подсказку и вторую попытку; затем полный разбор
• Карточки, экзамен с таймером, практика задач, повторение ошибок, избранное
• Статистика: прогресс по темам, история попыток, слабые места
• Работает без интернета, светлая и тёмная тема, крупный шрифт
• Без рекламы и трекеров

**Категория:** Образование. **Рейтинг:** для всех (IARC) / 4+ (Apple).

## Анкеты о данных

| Вопрос | Без сервера | С синхронизацией |
|---|---|---|
| Собирает ли данные | Нет | Да: email (аккаунт), учебный прогресс (действия в приложении) |
| Передаёт третьим лицам | Нет | Нет (Supabase — обработчик данных) |
| Шифрование при передаче | — | Да (HTTPS) |
| Можно удалить данные | Да (сброс) | Да (удаление аккаунта в приложении) |
| Реклама, трекинг | Нет | Нет |
| Разрешения устройства | Нет | Только интернет |

Скриншоты: снимайте на телефоне экраны «Предметы», «Главная предмета», «Тема → Формулы», «Вопрос с подсказкой», «Мой прогресс» — после того как в предметах появятся материалы.
